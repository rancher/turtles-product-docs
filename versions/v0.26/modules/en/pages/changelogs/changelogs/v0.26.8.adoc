== Description

Release Date: 2026-10-27

This v0.26 patch release pins the AWS cloud controller manager Helm chart to 0.0.11, updates the CAPV+RKE2 ClusterClass to the new SUSE Customer Center (SCC) registration for SL Micro 6.2, and bumps CAPRKE2 to v0.24.6, CAAPF to v0.14.2 and Go to 1.26.10. It also updates the Kubernetes dependencies to v0.34.12 and golang.org/x/net to v0.60.0 for a security fix.
