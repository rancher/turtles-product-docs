== Description

Release Date: 2026-09-18

This release adds a releaseChannel variable to the GKE ClusterClass, replaces the `rancher/kuberlr-kubectl` image with the `rancher/turtles` image in Helm hooks, and picks up security updates for `golang.org/x/mod`, `golang.org/x/crypto`, and `go.opentelemetry.io/otel`.


=== Other Changes

* chore(deps): update module golang.org/x/mod to v0.40.0 [security] (release/v0.26) by @renovate-rancher[bot] in https://github.com/rancher/turtles/pull/2791[#2791].
* chore(deps): update module go.opentelemetry.io/otel to v1.44.0 [security] (release/v0.26) by @renovate-rancher[bot] in https://github.com/rancher/turtles/pull/2790[#2790].
* Add releaseChannel variable to GKE clusterclass, bump GKE to 1.35.7 and Rancher to 2.14.4-alpha1 by @valaparthvi in https://github.com/rancher/turtles/pull/2783[#2783].

* chore(deps): update module golang.org/x/crypto to v0.56.0 [security] (release/v0.26) by @renovate-rancher[bot] in https://github.com/rancher/turtles/pull/2806[#2806].
