== Description

Release Date: 2026-10-21

This v0.26 patch release pins the AWS cloud controller manager Helm chart to 0.0.11, updates the CAPV+RKE2 ClusterClass to the new SUSE Customer Center (SCC) registration for SL Micro 6.2, and bumps CAPRKE2 to v0.24.5, CAAPF to v0.14.2 and Go to 1.26.10. It also updates the Kubernetes dependencies to v0.34.12 and golang.org/x/net to v0.60.0 for a security fix.


=== Notable Changes

* Pin AWS-CCM Helm chart version to 0.0.11 by @cpinjani in https://github.com/rancher/turtles/pull/2844[#2844].
