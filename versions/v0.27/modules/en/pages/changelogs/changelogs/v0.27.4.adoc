== Description

Release Date: 2026-10-27

Turtles `v0.27.4` is a patch version of the `v0.27` series, which is shipped as part of Rancher v2.15.3. This patch release fixes two controller bugs, one of them security-related. It also bumps CAPRKE2 to 0.25.3 and the Go toolchain to 1.26.10.


=== Notable Changes

* Fixed leaking registration url when download fails by @salasberryfin in https://github.com/rancher/turtles/pull/2962[#2962].
* Check for imported annotation after removing finalizers by @rancher-backport-assistant[bot] in https://github.com/rancher/turtles/pull/2936[#2936].

=== Other Changes

* Update go module directive to v1.26.10 (release/v0.27) by @renovate-rancher[bot] in https://github.com/rancher/turtles/pull/2946[#2946].
* Bump rancher-turtles-providers chart version by @salasberryfin in https://github.com/rancher/turtles/pull/2954[#2954].
* Bump caprke2 to v0.25.3 and prepare rancher-turtles-providers chart by @yiannistri in https://github.com/rancher/turtles/pull/2968[#2968].
* Bump rancher-turtles-providers chart version by @salasberryfin in https://github.com/rancher/turtles/pull/2982[#2982].
