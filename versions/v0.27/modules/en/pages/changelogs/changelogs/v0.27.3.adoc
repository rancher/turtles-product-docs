== Description

Release Date: 2026-10-21

Turtles `v0.27.3` is a patch version of the `v0.27` series, which is shipped as part of Rancher v2.15.3.


=== Notable Changes

This new release includes relevant changes that require your attention:

*Cluster API Add-on Provider Fleet (CAAPF) bumped to v0.15.1*

* The `rancher-turtles-providers` Helm chart now installs CAAPF `v0.15.1`.
** [release/v0.27] chore: bump CAAPF to `v0.15.1` by @yiannistri in https://github.com/rancher/turtles/pull/2874[#2874].

*AWS cloud controller manager Helm chart pinned to `0.0.11`*

* The AWS-CCM Helm chart version used by the AWS ClusterClass is now pinned to `0.0.11`.
** [release/v0.27] AWS-CCM: Pin helm-chart version to `0.0.11` by @cpinjani in https://github.com/rancher/turtles/pull/2842[#2842].

*CAPV+RKE2 ClusterClass: SCC registration updated*

* The SCC registration in the vSphere + RKE2 ClusterClass has been updated.
** [release/v0.27] CAPV+RKE2 clusterclass - update SCC registration by @thehejik in https://github.com/rancher/turtles/pull/2879[#2879].

*Security*

* Updated `golang.org/x/net` to `v0.60.0` to address a security advisory.
** chore(deps): update module `golang.org/x/net` to `v0.60.0` [security](release/v0.27) by @renovate-rancher[bot] in https://github.com/rancher/turtles/pull/2895[#2895].

=== Bug Fixes

* [release/v0.27] AWS-CCM: Pin helm-chart version to 0.0.11 by @cpinjani in https://github.com/rancher/turtles/pull/2842[#2842].

=== Other Changes

* chore(deps): update kubernetes dependencies to v0.35.9 (release/v0.27) by @renovate-rancher[bot] in https://github.com/rancher/turtles/pull/2853[#2853].
