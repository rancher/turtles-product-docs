== Release Date: 2026-07-22

== Description

This is the first Turtles release for Rancher 2.15 and it includes several improvements. Go module and GitHub Actions dependencies have been updated, including several security patches.

=== Notable Changes

* Add support for CAPI v1.13.3 by @anmazzotti in https://github.com/rancher/turtles/pull/2630[#2630].

=== Additions

* Translate Rancher AWS Cloud Credentials by @salasberryfin in [https://github.com/rancher/turtles/pull/2511#2511].

=== Bug Fixes

* Remove empty roles placeholder from aggregated_role by @thehejik in https://github.com/rancher/turtles/pull/2577[#2577].
* Update cluster registration token handling by @rancher-backport-assistant[bot] in https://github.com/rancher/turtles/pull/2638[#2638].
* Add provisional AI policy by @kkaempf in https://github.com/rancher/turtles/pull/2320[#2320].
* Improve Image Pull Secret Support by @HarrisonWAffel in https://github.com/rancher/turtles/pull/2335[#2335].
* Return error from DefaultSynchronizer.Get instead of silently dropping it by @immanuwell in https://github.com/rancher/turtles/pull/2462[#2462].
