== Description

Release Date: 2026-10-21

This patch release for v0.25 pins the AWS CCM Helm chart to 0.0.11, bumps CAAPF to v0.12.1 and Go to 1.26.10, updates the CAPV+RKE2 ClusterClass SCC registration, and picks up security updates to the Kubernetes, OpenTelemetry and golang.org/x/net dependencies.


=== Notable Changes

* Pin AWS-CCM Helm chart version to 0.0.11 by @cpinjani in https://github.com/rancher/turtles/pull/2843[#2843].
