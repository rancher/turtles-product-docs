== Description

Release Date: 2025-12-16

Rancher Turtles - Cluster API integration in Rancher.

This release of Rancher Turtles fixes an issue with fetching CAPI images in air-gapped environments. The new logic will use the Rancher setting system-default-registry to override the registry from where CAPI provider images are pulled.

* Rancher community: core CAPI is fetched from Docker Hub.
* Rancher Prime: CAPI providers are fetched from Prime registry.
