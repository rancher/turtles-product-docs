== Description

Release Date: 2025-02-27

This release of Rancher Turtles focuses on:

* Documentation improvements and restructuring:
** Added examples for RKE2 based docker, vsphere, gcp, aws and azure clusters.
ifeval::["{build-type}" == "product"]
** Updated the https://documentation.suse.com/cloudnative/cluster-api/latest/en/index.html[{product_name} documentation] with support for automatic stable version display with redirect to latest documentation release.
endif::[]
ifeval::["{build-type}" == "community"]
** Updated the https://turtles.docs.rancher.com[{product_name} Documentation] with support for automatic stable version display with redirect to latest documentation release.
endif::[]
* Updating Cluster API (CAPI) to v1.9.5 with support for cross-namespaced ClusterClasses.
* New experimental scaffolded features.clusterclass-operations feature, which will provide support for rollout ClusterClass rebases in the future.
* A new UI flag setting to enable day 2 operations via turtles: https://github.com/rancher/turtles/pull/1073[#1073].
* Bugfixes for ETCDSnapshotRestore day 2 operations.
* Includes provider releases: CAPRKE2 https://github.com/rancher/cluster-api-provider-rke2/releases/tag/v0.12.0[v0.12.0] and CAAPF https://github.com/rancher-sandbox/cluster-api-addon-provider-fleet/releases/tag/v0.6.0[v0.6.0] releases with important bug-fixes.
