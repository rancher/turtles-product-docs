== Description

Release Date: 2025-05-29

Rancher Turtles is an extension to Rancher that brings full Cluster API integration to Rancher.

This release of Rancher Turtles focuses on fixing bugs and improving the stability of the extension.

=== Bug Fixes

* Use ngrok operator in e2e suite by @alexander-demicev in https://github.com/rancher/turtles/pull/1335[#1335].
* Override CAAPF provider image source to downstream one by @Danil-Grigorev in https://github.com/rancher/turtles/pull/1353[#1353].
* Add oci option to fetchConfig validation by @mjura in https://github.com/rancher/turtles/pull/1357[#1357].
* Pin Calico chart to v3.29.3 by @anmazzotti in https://github.com/rancher/turtles/pull/1360[#1360].
* Pin calico chart version for AWS by @alexander-demicev in https://github.com/rancher/turtles/pull/1377[#1377].
* Set higher memory limits for the CAPI Operator by @Danil-Grigorev in https://github.com/rancher/turtles/pull/1382[#1382].
* Use SystemStore agent-tls-setting with ngrok by @anmazzotti in https://github.com/rancher/turtles/pull/1381[#1381].
* Fix AWS Kubeadm e2e by @anmazzotti in https://github.com/rancher/turtles/pull/1380[#1380].
