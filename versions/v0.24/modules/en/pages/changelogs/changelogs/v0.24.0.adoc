== Description

Release Date: 2025-09-15

Rancher Turtles is an extension to Rancher that brings full Cluster API integration to Rancher.

This release supports Rancher v2.12.1. Additionally, the CAPI version has been updated to v1.10.5. Several providers have also been updated to the latest available version.

=== Breaking Changes

The Rancher Fleet HelmApp CRD used by the Turtles ClusterClass examples, has been renamed to HelmOp in Rancher 2.12. Please follow the xref:user/clusterclass.adoc#_create_a_cluster_from_a_clusterclass[documentation] for migration instructions.
